# Coffee Shop

Landing page kedai kopi dengan bagian beranda, tentang kami, menu, dan kontak.
Proyek latihan HTML, CSS, dan JavaScript dengan tema **Kopi Kenangan**.

## ✨ Isi halaman

| Bagian | Isi |
| --- | --- |
| Beranda | Hero dan tombol ajakan pembelian |
| Tentang kami | Foto kedai dan deskripsi |
| Menu | Kartu produk dan harga |
| Kontak | Google Maps dan tampilan formulir |
| Navigasi | Tautan antarbagian dan menu hamburger pada layar kecil |

## 🚀 Menjalankan

Buka `index.html` di browser, atau gunakan Live Server dari editor.
Tidak ada dependensi npm, database, maupun proses build.

Font Poppins, Feather Icons, dan Google Maps membutuhkan koneksi internet.

## 🎨 Mengubah tampilan

| File/folder | Yang diubah |
| --- | --- |
| `index.html` | Nama kedai, teks, menu, harga, tautan, dan alamat iframe peta |
| `css/style.css` | Warna, tipografi, tata letak, dan responsivitas |
| `js/script.js` | Interaksi buka/tutup menu hamburger |
| `img/` | Foto hero, bagian tentang kami, dan menu |

<details>
<summary>Pemeriksaan sebelum dipublikasikan</summary>

- Periksa tampilan desktop dan ponsel, tautan navigasi, serta kartu menu.
- Buka menu hamburger lalu klik area di luarnya untuk memeriksa penutupan menu.
- Ganti teks contoh, menu berulang, dan tautan placeholder.
- Upload `index.html` bersama folder `css`, `js`, dan `img` ke hosting statis.

Belum ada pengujian otomatis pada proyek ini.
